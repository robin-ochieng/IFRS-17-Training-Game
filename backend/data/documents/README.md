# IFRS 17 Documents

Place your IFRS 17 PDF documents and related materials here.

## Recommended Documents

1. **IFRS 17 Insurance Contracts** - The official standard
   - Download from: https://www.ifrs.org/content/dam/ifrs/publications/pdf-standards/english/2022/issued/part-a/ifrs-17-insurance-contracts.pdf

2. **IFRS 17 Implementation Guidance** - Practical examples

3. **IFRS 17 Illustrative Examples** - Real-world scenarios

4. **Any internal training materials** - Company-specific guidance

## Supported Formats

- PDF (.pdf)
- Text files (.txt)
- Word documents (.docx, .doc)

## Ingestion

After adding documents, run the ingestion endpoint:
```bash
curl -X POST http://localhost:8000/api/ingest
```
